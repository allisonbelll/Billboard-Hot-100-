Data and method

How to read this dataset

One row represents one song appearing on one weekly Billboard Hot 100 chart. The source archive supplies the chart date, song, artist, current rank, previous rank, peak position, and weeks on chart. The preparation script adds year, decade, rank change, and movement. A positive rank change means the song moved upward because a smaller chart position is better.

The dataset is a 2010–2025 snapshot so the report and dashboard use the same fixed observations. Blank previous-week rank means the song was a new entry in that chart week. See the README for the source, transformation logic, and reproducibility instructions.
